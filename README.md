# Смета

Веб-приложение для подготовки коммерческих предложений и смет. Подрядчик собирает документ, проверяет расчёт и отправляет клиенту ссылку. Клиент может скачать документ, сообщить о согласии или запросить правки к конкретным позициям.

## Возможности

- Редактор с живым предпросмотром, этапами работ, скидками, расчётом НДС и графиком платежей. Цены и суммы рассчитываются до копейки.
- Скачивание PDF A4 и Excel. Импорт работ из CSV в UTF-8 и Windows-1251 с проверкой строк перед добавлением.
- Личный кабинет с черновиками, шаблонами, карточками заказчиков и справочниками услуг и подрядчиков.
- Версии с сохранёнными ценами и условиями, сравнение изменений, журнал событий, отзыв и архив.
- Учёт частичных оплат и напоминания о просрочках по графику.
- Восстановление доступа через почту. Docker включает Mailpit для локальной проверки писем.

Стек - PHP, Laravel, Vue 3, Vue Router, Vite, SQLite, MySQL и Docker Compose.

## Локальный запуск

Нужны PHP 8.5, Composer и Node.js 24. Для экспорта Excel требуются расширения PHP GD и ZIP.

```powershell
composer install
npm ci
npm run build
Copy-Item .env.example .env
php artisan key:generate
New-Item database/database.sqlite -ItemType File
php artisan migrate
php -S 127.0.0.1:8094 -t public
```

Откройте http://127.0.0.1:8094 и создайте кабинет. Чтобы загрузить примеры, зарегистрируйте кабинет с именем `test` и выполните `php artisan db:seed --class=PortfolioExamplesSeeder`.

Для запуска с MySQL подготовьте `.env` с ключом приложения и выполните `docker compose up --build`. Локальный Mailpit доступен на http://127.0.0.1:8025.

## Telegram Mini App

Локальная проверка: установите `TELEGRAM_LOCAL_DEMO=true` в `.env`, войдите в кабинет `test` и откройте `/mini`. Заявки и вопросы появятся на вкладке Telegram в кабинете. В .env можно указать `TELEGRAM_OWNER_ID` вместо кабинета `test`.

Для Telegram задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID` и публичный HTTPS-адрес `APP_URL`. Выключите локальный режим, настройте URL мини-приложения `/mini` в BotFather и запустите `php artisan queue:work` для отправки уведомлений. Чтобы бот мог писать клиенту, клиент должен сначала открыть диалог и запустить бота либо предоставить разрешение на отправку сообщений. Переписка также доступна в самом мини-приложении.

## Документы

Ставка НДС выбирается вручную по условиям сделки. Скидка учитывается до расчёта НДС. Доли платежей должны составлять 100% итога.

Веб-отклик клиента фиксируется отдельно от подписания. Смета доступна любому получателю ссылки.
